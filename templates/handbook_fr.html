ℹ Guide rapide pour les testeurs :
  • Touche Orange : La VOX est activée (l\'appareil transmet automatiquement). Il peut arriver que la PTT s\'allume brièvement en orange après avoir été relâchée, même si la VOX n\'est pas active. Bon sang, j\'y travaille.
  • S-SCAN : Le balayage s\'arrête en cas de signal. N\'importe quelle touche arrête le scan. La vitesse du scan peut être réglée en ms ci-dessous.
  • Super Sync : Maintenir enfoncé pendant 3 sec. pour forcer le canal 01 (si l\'affichage est asynchrone). Il est possible que la touche de modulation fonctionne de manière asynchrone. En remote, c\'est évidemment gênant. Solution : Ouvrez l\'ASQ et appuyez sur la touche Mode de l\'interface web jusqu\'à ce que vous entendiez le bruit typique de la FM, peu importe ce que l\'interface affiche. Utilisez ensuite la touche SYNC.
  • Clavier numérique : Choix du canal via le pavé tactile : Entrez toujours 2 chiffres (par ex. 07).
  • SKIP : La fonction "Skip PA / CW" concerne ceux qui ont déjà installé le nouveau firmware et désactivé le PA dans le menu Mode-Switch.
  • SCAN SPEED : Le S-Scan est géré par logiciel et indépendant de la fonction de scan intégrée à l\'AE5900. La vitesse peut être spécifiée en millisecondes.
  • P - Label : Les boutons P1 - P4 peuvent être dotés d\'une étiquette visuelle ici. Conformément à ce qui est configuré sur l\'AE5900 dans l\'option de menu Mic Type 2.
  • Vol - et Vol + : Le MicGain de la carte son intégrée / Mumble.
  • PTT Timeout : Le PTT Timeout sert de sécurité supplémentaire pour éviter que l\'AE5900 ne continue à transmettre pendant une longue période en cas de perte de connexion.
  • MW : Multiwatch balaie les canaux prédéfinis. Entrez simplement les canaux à scanner, séparés par des virgules. Exemple : 01,04,09,28
  • MUTE : Coupe complètement le son de l\'AE5900.
  • A/SQ + / - : Permet de régler le niveau de l\'ASQ (si activé) ou du Squelch. L\'ASQ dispose de 9 niveaux, le Squelch de 80 niveaux.
  • SET A/SQ 1/0 : Pour éviter de se fatiguer les doigts : Une réinitialisation qui ramène les niveaux d\'un maximum de 80 à 1 (ASQ) ou 0 (Squelch).
  • CLAR / STEP : Le Clarifier est uniquement activé en modes CW, USB et LSB. Appuyez sur STEP pour choisir entre 1, 10 ou 100 Hz, puis appuyez sur CLAR + ou CLAR -.
  • LOCK : Verrouille toutes les touches de l\'AE5900 et de l\'interface Web, à l\'exception du bouton Lock.
